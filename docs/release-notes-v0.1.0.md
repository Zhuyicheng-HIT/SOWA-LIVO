# SOWA-LIVO v0.1.0

## English

- Independent, ROS-free Linux x86_64 SOWA C++ core binary.
- Public interface headers, CMake integration, and lightweight ROS 1 adapter source.
- One-command installation for Ubuntu 20.04 / ROS Noetic and WSL2 / Docker environments.
- Frozen long-corridor configuration and SHA-256 checksums.
- Historical full-L reference: v0.7.6 Dynamic Route A, 3D RMSE 0.510570 m.
- Core source code will be released upon paper acceptance.

- 发布独立、无 ROS 依赖的 Linux x86_64 SOWA C++ 核心二进制库。
